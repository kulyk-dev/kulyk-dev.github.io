# CLAUDE.md

Рабочая инструкция для Claude в этом репозитории. Пишем по-русски, если не сказано иначе.

## Структура репозитория

```
CLAUDE.md                 # этот файл: правила и карта проектов
projects/<name>/          # один проект = одна папка с README.md и исходниками
notes/                    # Obsidian-хранилище: заметки, планы, решения
.github/workflows/        # деплой сайта клуба
```

Каждый проект в `projects/` содержит `README.md` со статусом, целью и связями.

## Правила работы

- Один проект — одна папка. Новый проект сначала получает папку с `README.md`.
- Не трогать `projects/club-site/` без причины: по адресам сайта работают QR-коды на распечатанных столах.
- Сайт публикуется из `projects/club-site/` через GitHub Actions (`.github/workflows/pages.yml`). В настройках Pages должен стоять источник «GitHub Actions».
- Коммиты и пуш делаем только по команде пользователя. Изменения вносим на отдельной ветке, в `main` — через PR.
- В коммитах и PR не пишем название модели.
- Секреты, токены, пароли и личные данные в репозиторий не кладём.
