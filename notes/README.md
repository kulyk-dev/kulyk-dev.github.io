# Notes — Obsidian-хранилище

Это Obsidian-хранилище. Открывается в Obsidian через «Open folder as vault» → папка `notes/`.

- `Inbox/` — быстрые мысли, не разобранные.
- `Projects/` — заметки и планы по проектам (по одной на проект).
- `Decisions/` — решения: что решили, почему, когда.
- `Daily/` — дневник и ежедневные записи.

Связи между проектами делаем через `[[wikilinks]]`, например `[[video-manager]]`.

## Подключение к Claude через GitHub

1. В Obsidian установить плагин «Obsidian Git».
2. Указать репозиторий `kulyk-dev.github.io` как Git-папку, а путь — `notes/`.
3. Включить автопуш/автопулл по расписанию (например, каждые 10 минут).

Так заметки синхронизируются между Obsidian и Claude. Пуш в `main` делаем только по команде.
